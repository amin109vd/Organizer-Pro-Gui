📁 Folder Organizer Pro

A powerful, modern desktop application that automatically organizes your files into structured folders based on file types. Built with Python and Tkinter, featuring a beautiful UI and real-time file monitoring.

🚀 Features

- ⚡ One-click file organization
- 🧠 Smart category-based sorting (Videos, Music, Documents, etc.)
- 🔄 Auto-detect unknown file types
- 👁 Real-time folder monitoring (Watch mode)
- 🗂 Custom category editor (add/remove/edit file types)
- 🚫 Ignore specific file extensions
- 💾 Auto-save configuration
- 📊 Live activity log with filters
- 🎨 Modern dark UI design
- 🖥 System tray–like background automation

## 📂 How It Works

The app scans your selected folder and automatically sorts files into categories like:

* 🎬 Videos → `.mp4, .mkv, .avi`
* 🎵 Music → `.mp3, .wav, .flac`
* 🖼 Images → `.jpg, .png, .gif`
* 📄 Documents → `.pdf, .docx, .txt`
* 📦 Archives → `.zip, .rar, .7z`
* 💻 Code → `.py, .js, .html`
* 🧩 Others → uncategorized files

You can fully customize categories in the app UI.

---

👁 Watch Mode

When enabled, the app continuously monitors your folder and automatically organizes new files in real time.

---

⚙ Configuration

Settings are saved automatically at:

```
C:\Users\YourName\.folder_organizer_config.json
```
